# Modern CRM Uygulaması

Next.js (App Router) ile geliştirilmiş rol bazlı CRM uygulaması.

## Modüller
- Satış: müşteri yönetimi, fırsat pipeline
- Teknik Servis: servis ticket yönetimi
- Muhasebe: fatura ekranı
- Tüm roller: dashboard ve raporlar

## Roller
- admin
- sales
- service
- finance

## Geliştirme
```bash
npm install
npm run dev
```

## Replit Deploy
Bu repo Replit deploy için `.replit` ve `replit.nix` dosyalarını içerir.
